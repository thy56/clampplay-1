# Concept Models

This directory contains concept-stage mechanical models for discussion and early engineering review.

- `guitar_fret_assist_mechanical_v2.*`: exposed guitar fretting mechanism concept.
- `kick_drive_mechanical_v2.*`: exposed kick-drive transmission concept.
- `build_mechanical_cutaways.py`: Blender generation script.
- `verify_mechanical_v2.py`: artifact validation script.

The models are not production CAD. Do not manufacture directly from them without completing dimensions, tolerances, load calculations, safety review, and physical validation.
