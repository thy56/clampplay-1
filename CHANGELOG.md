# Changelog

All notable changes to this project are documented in this file.

## 0.1.0 - 2026-10-01

### Added

- Mobile-first PWA for local performance-event preparation, calibration records, safety status, and Web Serial entry.
- Python reference implementation for the fixed 14-byte controller protocol and event scheduling.
- Arduino-compatible serial firmware skeleton with checksum validation, actuator-index checking, stop handling, and 1000 ms command-timeout release.
- Browser interaction prototypes for piano, guitar, and drum execution flows.
- Concept models for a guitar fretting mechanism and a kick-drive transmission.
- Editable system and execution-chain diagrams.
- Split licensing: MIT for software and CERN-OHL-S-2.0 for hardware design materials.

### Notes

- This release is a concept and software prototype. It does not claim completed instrument hardware validation, real-instrument automatic performance, or user trials.
